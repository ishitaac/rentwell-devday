# Sample photos (optional)

Drop JPEGs here to replace the illustrated sample photos in the demo tour and "See sample results".
Name each file after the stop it stands in for:

sink, ceiling, tub, window, floor, appliances, stairs, exterior, yard, mechanical, hallway, outlet, garage, anything

For example `ceiling.jpg`. Keep each under ~300 KB (longest side ~1200 px).

Rules: use your own photos or clearly licensed, non-listing images. No people, personal items, or
license plates. Each photo should actually show the saved sample finding for that stop
(see `SAMPLE_OBSERVATIONS` in `src/walkthrough/sample.ts`: for example `ceiling.jpg` should show a
brown stain in the upper right corner, and `appliances.jpg` should be too dark to read).
